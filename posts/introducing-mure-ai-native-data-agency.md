## The game has changed. Services are the new software.

Agencies have always been brutally hard to scale. Thin margins, slow manual work, and the only path to growth was hiring more people. We experienced that in the past. But AI changes the equation, and [services are becoming the new software](https://sequoiacap.com/article/services-the-new-software/).

Think about a data agency. Instead of manually building data infrastructure for every client, you can now run SQL, pipelines, and infra using AI. You don't just deliver data systems. You build leverage into every engagement.

**The agencies of the future will look like software companies. We're building that**.

## Announcing Mure: The AI-native data agency

We're an AI-native data agency: we embed with companies to build agentic data systems, and we're building the platform that powers it.

The platform helps data practitioners and agents reason about the ecosystem and interact with data backends in a fundamentally new way. It's built on three pillars:

- an **ecosystem reasoning** layer that helps humans and agents understand what's happening in the data and AI space
- a **data infrastructure** layer that exposes data backends like a filesystem
- an **agency runtime**, the metamodel behind how we operate and deliver

**This is our vision**.

## What's next

Every engagement we run sharpens what we build. The [agency](/#services) work and the platform compound each other. More is coming across all three layers.

**Let's build agentic data systems, together**.
